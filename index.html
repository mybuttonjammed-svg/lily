🐸 MemeCoin Pet

Browser installer template for the LILYGO T-Dongle-S3.

Not ready to flash yet. Compile and host a merged ESP32-S3 firmware binary, then replace the placeholder URL in manifest.json. Do not click Install expecting this template to contain firmware.

Use desktop Chrome or Microsoft Edge with Web Serial support, on an HTTPS website.

Source code and setup notes are in the project README.
